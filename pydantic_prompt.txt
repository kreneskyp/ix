Generate wrapper functions for each of these functions
why: the functions don't allow kwargs to be set on the BaseTool object.
requirements:
- each function should return a BaseTool
- import extract_tool_kwargs from ix.chains.loader.tools
- do not redefined extract_tool_kwargs in the files.
- use the load_openweathermap function as an example
- group functions into files

EXAMPLE:

def load_openweathermap(**kwargs) -> BaseTool:
    """
    Load the OpenWeatherMap tool.
    """
    tool_kwargs = extract_tool_kwargs(kwargs)
    wrapper = OpenWeatherMapAPIWrapper(**kwargs)
    return OpenWeatherMapQueryRun(api_wrapper=wrapper, **tool_kwargs)

    return Tool(
        name=kwargs["awslambda_tool_name"],
        description=kwargs["awslambda_tool_description"],
        func=LambdaWrapper(**kwargs).run,
